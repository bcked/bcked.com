# Comments

Praise and doubts about the backing of an asset, shown on its page on bcked.com.

Each asset has a folder named by its API ID (e.g. `ethereum:0xdAC17F958D2ee523a2206206994597C13D831ec7`).
Files are named `praise-<n>.md` or `doubt-<n>.md`. The first heading is the title, the rest is the comment.
